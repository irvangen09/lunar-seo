A lightweight, modular WordPress SEO plugin that follows WordPress Coding Standards.

== Description ==

Lunar SEO is a lightweight, modular SEO plugin designed for content-focused sites (blogs, docs, wikis), focusing on essential features rather than bloat. It features three independent modules: General (SEO meta, OG tags, verification), Sitemap (automatic XML sitemap), and Schema (automated JSON-LD).

== Installation ==

1. Upload to `/wp-content/plugins/lunar-seo` or install via WordPress.
2. Activate the plugin.
3. Configure settings via the 'Lunar SEO' menu.

== Frequently Asked Questions ==

= Can I use this with another SEO plugin? =
Not recommended, as it can cause duplicate meta tags or sitemaps.

= Is my settings data lost if the plugin is deactivated? =
No, data is only removed when the plugin is fully deleted.
